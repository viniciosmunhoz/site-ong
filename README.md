# Site ONG

## Sobre o projeto

Site institucional fictício de uma organização não governamental,
desenvolvido como atividade da disciplina de Desenvolvimento
Front-end para Web.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Navegação SPA (Single Page Application)
- Layout responsivo
- Formulário com validação de CPF
- Máscara de telefone
- Persistência de dados com localStorage
- Navegação por histórico do navegador

## Como executar

Abra o arquivo index.html em um servidor local,
como o Live Preview do VS Code.
